Qwen 2.5 ChatML

Modern instruction-tuned LLMs like Qwen 2.5-1.5B wrap user prompts inside structured delimiters. This prevents prompt injection and delineates system instructions from user inputs:

<|im_start|>system
You are a helpful assistant. Provide concise, complete, and direct answers.<|im_end|>

Stage 3: Discrete Integer Vocabulary Lookup

Vocab Size: 151,936

Each token string maps bijectively to a 32-bit integer in the Qwen 2.5 vocabulary matrix (vocab_size = 151,936). Special control tokens reside in reserved ranges (>151643).

PROJECT PHASE 2 - LocalGPT

ChatGPT-Style Local AI Assistant with RAG and LLM X-Ray

1. Project Overview

Build a local ChatGPT-style AI application that allows users to have continuous conversations with an LLM, upload documents, ask questions about those documents, maintain conversation history, and inspect the internal LLM inference process.

The application will use the same local Hugging Face LLM from Project 1, so no external LLM API is required.

↓

↓

Optional:
Response
↓
LLM X-Ray
↓
Tokens → Embeddings → Layers → Attention → Hidden States → Logits → Probabilities

The X-Ray functionality from Project 1 becomes an advanced inspection mode rather than the main interface.

2. Main Objective

The goal is to upgrade the existing LLM X-Ray into a practical local AI assistant similar to ChatGPT.

The system should support:

  • Multi-turn conversations
  • Conversation history
  • Context-aware responses
  • Streaming text generation
  • Regenerate response
  • Edit user messages
  • Copy responses
  • Markdown rendering
  • Code formatting
  • System prompt
  • Temperature / Top-K / Top-P controls
  • Document upload
  • Question answering from documents
  • Conversation-based memory
  • LLM X-Ray inspection

The application should still run locally on a personal laptop.

3. Model

Use the existing model:
Qwen/Qwen2.5-1.5B-Instruct

This keeps Project 2 compatible with Project 1 and avoids requiring an external API. Project 1 already specifies this model as a locally runnable, instruction-tuned Hugging Face model.

PROJECT PHASE 1 - LLM X-RAY

Interactive Visualization of LLM Inference

1. Project Overview

Build a local LLM application that accepts a text prompt, generates a response using a Hugging Face model, and visually shows what happens inside the model during inference.

Core Flow
Input → Tokenization → Token IDs → Embeddings → Transformer Layers → Attention → Logits & Probabilities → Response

2. Model

Qwen/Qwen2.5-1.5B-Instruct (1.54B parameters, 28 layers, 1536 dim, Apache 2.0 license).

3. Technology Stack

Python, PyTorch, Transformers, Streamlit, Plotly, Scikit-learn, NumPy.

4. Implementation Steps (1 to 3)

Step 1: Setup LLM-XRay/
Step 2: Load Qwen2.5-1.5B-Instruct
Step 3: Build Chat Interface

Step 4 & 5: Tokenization & Embeddings

Tokenization → Token IDs → 1536-dim Embeddings → 2D PCA Space

Step 6 to 8: 28 Layers, Attention Heatmaps, Hidden States

Layers 1-28 → Multi-Head Attention Heatmap → Hidden States PCA

Step 9 & 10: Logits & Token Generation

Hidden State → LM Head → Logits → Softmax → Next Token Rollout
